# 05 — Role and security matrix
Built-in roles (from `dealerTeamRoles.service.js`): manager, sales_agent, lot_agent, finance_officer, viewer, plus owner-defined custom roles. The full role × 11-probe matrix, banking/finance/subscription denial for every role, manager denied team management, cross-dealer access denial and suspension/removal cut-off were verified earlier by `16_isolation_and_sessions.mjs` (PASS in the FINAL-COMPLETION run) and are reinforced here by journey 17 (D6–D10). Hiding UI is not relied on: all checks are direct API calls.
Last-owner protection: the owner is the dealer account itself, not a removable `dealer_teams` row, so a dealership cannot lose its owner through the Team API (design finding, no test of a "last owner" row exists because none can exist).
Session revocation on removal: access is re-evaluated on every request (membership is re-read), so removal takes effect immediately (D10). Refresh-token revocation of the member's personal session is NOT applicable/changed: the personal session stays valid for the member's own account, only dealership access ends.
