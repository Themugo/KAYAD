# Runbooks and historical execution records

This directory contains dated, phase-labelled operational procedures and test harnesses retained from prior work. Names such as `phase14-9-20261026` and `stage5e1-20261020` identify historical execution batches; they are not application packages, deployment environments, or canonical product phases. Keep their original names and relative paths when preserving or reproducing historical runs. New evergreen operational procedures should use descriptive names and be indexed from `docs/README.md`.
