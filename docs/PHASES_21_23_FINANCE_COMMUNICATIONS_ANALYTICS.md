# Phases 21–23 — Finance, Communications & Analytics

## Phase 21
Invoice creation, line-item totals, payments and status changes use server-side transactional RPCs with staff authorization and payment-overbalance protection.

## Phase 22
Customer communications are stored as a canonical, staff-attributed timeline supporting email, WhatsApp, phone, SMS and internal notes. External sending providers can be attached later without changing the data model.

## Phase 23
Business analytics exposes a protected 30-day snapshot combining website visits, orders, sales, invoicing, collections, outstanding balances and top pages.

Live Supabase migration and production build validation remain intentionally separate from this source initiative.
