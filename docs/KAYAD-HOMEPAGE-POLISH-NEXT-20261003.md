# KAYAD Homepage Polish — Next Controlled Pass

## Scope
Presentation-only homepage refinement from the controlled homepage foundation.

## Changes
- Reduced the hero headline scale and tightened its measure for a more professional editorial hierarchy.
- Centered the hero message as the visual anchor between two vehicle subjects.
- Converted hero vehicle stages from boxed product cards to floating editorial vehicle artwork.
- Preserved real featured vehicle imagery and existing curated fallback assets.
- Improved desktop perspective, overlap, glow and shadow treatment around the vehicle subjects.
- Kept mobile hero vehicles visible without allowing them to dominate the message card.
- Removed zero-value marketplace counters from the compact marketplace header when inventory is unavailable.
- Updated the default hero/editor headline to `Find a vehicle worth driving home.`.
- No marketplace data, API, navigation, authentication, payment, escrow, inspection, or deployment behavior was changed.
