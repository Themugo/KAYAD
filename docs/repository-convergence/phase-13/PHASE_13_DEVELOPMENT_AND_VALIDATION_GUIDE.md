## Suggested safe validation order
1. Read the project README and contributor/development instructions.
2. Confirm runtime version and package manager from committed files.
3. Inspect scripts and CI workflow definitions.
4. Obtain owner approval before installing dependencies if it would modify workspace state.
5. Run focused static checks in an isolated working copy, recording exact commands, exit codes, and logs.
6. Run application test suites only under a separately approved validation plan.
