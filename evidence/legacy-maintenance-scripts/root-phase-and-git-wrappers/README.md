# Archived root phase/apply wrappers

These files were moved out of the KAYAD root during Phase 23 because they are historical phase-specific apply/recovery/certification wrappers or commit/push scripts, and no active non-historical repository references were found in the scanned tree. Several contain hardcoded workstation paths, overwrite/extract/copy behavior, or Git mutation commands.

**Do not execute these archived wrappers.** Their original bytes are preserved for provenance. Relocation changes their relative source-directory assumptions, so this directory is evidence storage, not an executable package. If a future recovery requires one, reconstruct and independently review the original package in a disposable workspace; do not run directly against a working or production repository.

Historical documentation and manifests are intentionally not rewritten. Mentions of former root paths are retained as historical evidence.
